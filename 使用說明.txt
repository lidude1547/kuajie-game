跨界溝通大挑戰：現場互動遊戲 使用說明
========================================
本遊戲有三種開法，依場地選擇：

  A. 區網版（http）  場地有穩定 Wi-Fi，且手機之間能互連
  B. https 通道版    想給全場一個 https:// 網址、或場地 Wi-Fi 擋互連（最推薦，免註冊）
  C. 雲端固定網址版  想要永久固定的 https:// 網址（例如 https://xxx.onrender.com）

------------------------------------------------------------
【共同的事前準備】
安裝 Node.js（https://nodejs.org ，版本 16 以上，下載 LTS）。

------------------------------------------------------------
【A. 區網版】
Windows 連按兩下「開始遊戲.bat」；Mac 連按兩下「開始遊戲.command」
（第一次若被擋，請在檔案上按右鍵 → 打開）。
瀏覽器會打開主持人畫面，投影並按 F11 全螢幕；觀眾手機必須連到同一個 Wi-Fi 後掃 QR code。
場地 Wi-Fi 若有「用戶隔離」而掃了打不開，請改用 B，或讓講者手機開熱點。

------------------------------------------------------------
【B. https 通道版（推薦）】
讓觀眾用任何網路（Wi-Fi 或手機 4G/5G）都能開，網址是 https://xxxx.trycloudflare.com。
1. 一次性安裝 cloudflared（Cloudflare 的免費小工具，不需註冊帳號）：
   - Windows：開啟 PowerShell 輸入  winget install --id Cloudflare.cloudflared
   - Mac：終端機輸入  brew install cloudflared
2. 連按兩下「開始遊戲_https通道.bat」（Mac：「開始遊戲_https通道.command」）。
3. 在通道視窗的輸出裡找到 https://xxxx.trycloudflare.com，複製起來。
4. 在主持人畫面（左側 QR 卡片下方）貼上該網址，按「套用」，QR code 就變成 https 網址。
5. 把同一個網址也貼到簡報或聊天室，沒辦法掃碼的人可直接輸入。
注意：每次啟動，網址都會不一樣，請在活動前先開一次確認。講者電腦需要有網路。
安全：透過通道進來的人，一律視為觀眾，不能開啟主持人畫面或操作流程。

------------------------------------------------------------
【C. 雲端固定網址版（需自己的 GitHub 與 Render 帳號，都有免費方案）】
1. 把這個資料夾的檔案（server.js、index.html、package.json、render.yaml）放進一個 GitHub 儲存庫。
2. 到 https://render.com → New → Web Service，選該儲存庫。Start Command 填  node server.js
3. 在 Environment 新增變數  HOST_KEY  ，值填一組只有你知道的密碼（例如 k8m3x9）。
4. 部署完成會得到 https://你的名稱.onrender.com。觀眾用這個網址；
   主持人畫面是  https://你的名稱.onrender.com/host?key=你的密碼
   （QR code 會自動指向正確的 https 網址）。
注意：免費方案閒置一段時間會休眠，第一次開啟要等約 1 分鐘，活動前請先開啟喚醒。
      資料存在伺服器記憶體裡，服務重啟就會清空，所以請在活動結束後立刻匯出 CSV。

------------------------------------------------------------
【主持人操作】
- 畫面最下方橘色大按鈕＝下一步；也可以按鍵盤「空白鍵」或「→」。「←」回到上一階段。
- 上方 入場 / R1 / R2 / R3 / R4 / R5 / Q&A / 結束，可以點一下直接跳到該階段。
- 流程：入場（掃碼、暖身）→ R1 現場溫度計 → R2 翻譯機搶答（5 題、每題 20 秒）→
  R3 嵌入大挑戰（4 題、每題 25 秒）→ R4 溝通小劇場（3 個情境、不計分）→
  R5 行動承諾牆 → Q&A 提問牆 → 結束。
- 搶答題倒數結束會自動揭曉；也可提前按「揭曉答案」。
- 觀眾隨時都可以在手機「提問」分頁送出問題，不必等到 Q&A 階段。
  Q&A 畫面可按「已回答」「隱藏」整理；右上角紅色圓點顯示尚未回答的提問數。
- 結束畫面可「匯出紀錄（CSV）」：提問、承諾、溫度計結果、排行榜。用 Excel 開啟即可。
- 「重設全場」會清空所有資料（要連按兩次才會執行）。
- 本機版每 10 秒自動備份到 session-backup.json；意外中斷時，用 node server.js --resume 可還原。

【隱私與安全】
- 觀眾暱稱不必真名；身分只用在分組統計；個別答案不會公開。
- 本機版與通道版：資料只存在講者電腦。活動結束後可刪除 session-backup.json。
- 約 200 人同時連線經過模擬測試。

【排練／無網路】
直接用瀏覽器開啟 index.html（不執行伺服器）＝示範模式：有 24 位模擬觀眾與手機預覽，
可練習整場流程。示範模式的 QR code 不是真的。

【修改題目】
所有題目與解析寫在 index.html 內（搜尋 CONTENT），可用文字編輯器修改，存檔後重開 server。
各題「較建議」的回應是講者建議的溝通框架（描述—理解—邀請），並非唯一標準答案。
